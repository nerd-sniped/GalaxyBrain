# Second Brain

The "Second Brain" is a methodology for building a personal knowledge management (PKM) system. ^pkm-definition

Coined by Tiago Forte, the PARA method organises information into:

- **Projects** — active work with deadlines
- **Areas** — ongoing responsibilities  
- **Resources** — reference material (like this garden)
- **Archives** — inactive items ^para-method

## Connection to Digital Gardens

A [[Digital Garden]] is one possible implementation of a second brain. The key difference is that a digital garden is **public** — the act of publishing forces better writing and thinking. ^garden-vs-brain

## Tools

[[Obsidian]] is the tool used to build this second brain. It stores everything as plain #markdown files, ensuring longevity and portability.
