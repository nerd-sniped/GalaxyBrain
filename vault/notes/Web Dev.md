# Web Dev

Web development covers building applications that run in the browser or on web servers.

## Frontend Stack Used Here

This garden uses a modern static-site approach:

| Layer | Technology |
|---|---|
| Framework | [[Astro]] |
| Language | [[TypeScript]] |
| Interactivity | React islands |
| 3D rendering | Three.js |
| Hosting | Netlify |

## The Static-Site Renaissance

Modern static site generators like [[Astro]] have made it practical to build highly interactive sites that ship minimal JavaScript — the "islands architecture".

This contrasts with heavy SPA frameworks where the entire UI is JavaScript-driven.

## #programming/web Ecosystem

The #programming/web space moves fast. Key trends:

- Zero-JS by default (Astro, 11ty)
- Edge computing (Netlify Edge Functions, Cloudflare Workers)
- Type-safety end-to-end ([[TypeScript]] + Zod)
