## Why These Languages

The common thread: #programming languages that make large-scale correctness tractable.

Both [[Rust]] and [[TypeScript]] enforce correctness at compile time rather than at runtime. This shifts the cost of bugs leftward in the development cycle.

> [!tip] Learning Path
> Start with [[TypeScript]] if you have web experience. Move to [[Rust]] when you want to understand systems concepts.
