# Note Taking

Effective note taking is fundamentally about **creating retrievable, connectable knowledge** — not just capturing information.

## Principles

1. **Write in your own words** — summarising forces comprehension ^cornell-method
2. **Link aggressively** — connections between ideas are the real value
3. **Revisit and refine** — notes improve over time

## Atomic Notes

The "atomic note" principle: each note covers exactly one idea. This makes notes reusable across many contexts. ^atomic-note

[[Obsidian]] implements this well with wikilinks — you can reference any note from any other note.
